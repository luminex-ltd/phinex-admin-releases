# Phinex Admin Dashboard downloads

Direct downloads of the Phinex Admin Dashboard for macOS and Windows, for Phinex staff. The dashboard is
not in the App Store or the Microsoft Store. The source code is private; this repository only holds the
release files, published automatically by its release workflow. The download page is
https://phinex.app/admin/download.

| Computer | Download (always the latest version) |
| --- | --- |
| Any Mac | [PhinexAdmin-macOS-Universal.dmg](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-macOS-Universal.dmg) |
| Mac with Apple silicon | [PhinexAdmin-macOS-AppleSilicon.dmg](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-macOS-AppleSilicon.dmg) |
| Intel Mac | [PhinexAdmin-macOS-Intel.dmg](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-macOS-Intel.dmg) |
| Any Windows PC | [PhinexAdmin-Windows-Setup.exe](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-Windows-Setup.exe) |
| Windows x64 | [PhinexAdmin-Windows-x64-Setup.exe](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-Windows-x64-Setup.exe) |
| Windows on ARM | [PhinexAdmin-Windows-arm64-Setup.exe](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-Windows-arm64-Setup.exe) |
| Windows, no installer | [x64](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-Windows-x64.zip) · [ARM64](https://github.com/luminex-ltd/phinex-admin-releases/releases/latest/download/PhinexAdmin-Windows-arm64.zip) |

Checksums for every file are in `SHA256SUMS.txt` on each release.

The app needs the `.env` file you were given, placed next to it. On Windows, the installer may show
"Windows protected your PC": choose **More info › Run anyway**.
